# Hannah Maths Games

A GitHub Pages-ready collection of three browser maths games:

- Multiplication / Times Tables
- Division
- Fractions

## Structure

- `/index.html` — game launcher
- `/multiplication/index.html`
- `/division/index.html`
- `/fractions/index.html`
- `/.nojekyll`

All games are self-contained static HTML/CSS/JavaScript and require no backend.
